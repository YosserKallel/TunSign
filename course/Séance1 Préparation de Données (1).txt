Une donnée est dite imprécise quand on ne peut pas lui attribuer une seule valeur 
exacte, mais plutôt :

• une fourchette
• un label linguistique (ex: “jeune”, “chaud”, “lent”)
• une probabilité ou possibilité (logique floue)

Transformation des données
2.1 Transformer les données
C. Normalisation : Uniformisation d'échelle
• Si on laisse ces échelles telles quelles :
✓ les algorithmes vont donner plus d’importance aux variables dont les 
valeurs sont grandes
✓ les calculs de distance (KNN, K-means…), gradient, etc., deviennent 
déséquilibrés
➔ Résultat : le modèle est biaisé.
❖ La solution : Normalisation (Uniformisation d’échelle)
• La normalisation consiste à ramener toutes les variables sur la même 
échelle, souvent entre 0 et 1, ou autour de 0 avec un écart-type de 1.
➔ Toutes les variables pèsent de manière équivalente dans les calculs.
